the first prompt

Act as an expert full-stack developer assisting a beginner team for a hackathon. We are short on time and need an easy-to-manage, working prototype.

Build the project using ONLY a simple 3-file structure:

index.html (contains our HTML layout, modern CSS styling, and client-side JavaScript)

app.py (lightweight Python Flask backend with flask-cors)

requirements.txt (only flask and flask-cors)

Rules:

Do NOT use React, Next.js, Vite, TypeScript, or nested component folders.

For our project idea: [Cooperative Gig Services Platform for Household & Community Services].

Build the core landing screen and the main input form.

Ensure every <input> and <button> has working JavaScript event listeners attached.

Provide the exact 2 terminal commands to install packages and start the app on localhost."





















Prompt 2: Connect Frontend to Backend (No Broken Mocks)

"Now connect the form in index.html to app.py:

In app.py, write a real POST route (/api/submit) that accepts JSON input, processes it, and returns a JSON response.

In index.html, write a vanilla JS fetch() call on form submit that sends the inputs to /api/submit.

Display the returned response dynamically inside a result <div> on the page without refreshing.

Do not add new files or dependencies. Keep everything inside index.html and app.py."



















Prompt 3: Instant Mock Authentication (Zero Setup)

"Add a clean, working login modal to index.html:

Do NOT use complex database auth, OAuth, or external auth providers.

Use browser localStorage to simulate a session.

Any username/password entered should successfully 'log in', save isLoggedIn = true to localStorage, hide the login form, and display the user's name on the dashboard.

Add a simple 'Logout' button that clears localStorage and resets the view."

































Prompt 4: Emergency Bug Fixer (Use When Code Breaks)
"The form/button is not responding when clicked. Do not create new files. Inspect index.html and app.py and fix:

Check browser console errors and ensure IDs in the HTML match the JavaScript document.getElementById calls.

Ensure CORS is enabled in app.py so the browser doesn't block the request.

Add console.log() statements on every step so we can track the data flow in the browser DevTools (F12).
